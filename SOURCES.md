# Sources

Every document the dataset uses. Primary sources are archived, unmodified, as assets of
the `sources-2026-10-21` release; each belongs to its publisher, and this dataset is a
derived compilation. The SHA-256 is of the file as retrieved on 2026-10-21.

Publisher terms: **MEW** (Ministry of Electricity, Water and Renewable Energy, State of Kuwait): no
licence stated; © MEW. **CSB** (Central Statistical Bureau, State of Kuwait): the data use policy
allows downloading and copying with copyright notices kept; not a named open licence.
**UNdata** (UN Statistics Division): may be copied and redistributed with attribution.

Not used: commercial resellers (CEIC, Enerdata, Statista, Knoema); the IEA (its terms forbid
redistribution). The Arab Union of Electricity is reserved for a peak-load check that publishes
agreement only, never its values (not yet done).

الطاقة الكهربائية والمياه (2013: الكهرباء والغاز والماء). The UNdata hash is of the rows as parsed
from its pages, since UNdata's file download does not work.
